# ⚔️ RPG Quest Journal & Hero Dashboard

Усложненный интерактивный таск-менеджер с элементами **RPG-игры**, разработанный на современном бэкенд-стеке Python. Проект превращает выполнение повседневных задач в прокачку персонажа: за выполнение квестов начисляется опыт (XP), игровое золото (Gold) и повышаются реальные характеристики героя (Интеллект, Сила, Ловкость). Накопленные ресурсы можно тратить во встроенной лавке наград на легальный отдых.

## 🚀 Технологический стек

* **Бэкенд-фреймворк:** FastAPI (Python 3.12+)
* **База данных:** PostgreSQL 16 (развернута в изолированном Docker-контейнере)
* **ORM (Управление БД):** SQLAlchemy 2.0+
* **Валидация данных:** Pydantic v2
* **Драйвер подключения:** Psycopg 3 (Binary)
* **Фронтенд:** Асинхронный графический интерфейс (HTML5, CSS3, JavaScript Vanilla)

## 🎮 Игровые механики и архитектура БД

В базе данных развернута реляционная структура, связывающая следующие сущности:
1. **Профиль Героя (`hero`):** Хранит уровень, текущий опыт, планку до следующего уровня (Level Up рассчитывается по формуле `XP * 1.4`), баланс кошелька и базовые статы.
2. **Категории квестов (`categories`):** Каждая категория привязана к своей характеристике. 
   * `Учеба 🧠` — увеличивает Интеллект.
   * `Спорт и Дом 💪` — увеличивает Силу.
   * `Дела и Работа ⚡` — увеличивает Ловкость.
3. **Журнал квестов (`tasks`):** Хранит активные и выполненные задачи, рассчитывая награду динамически.
4. **Лавка Наград (`shop_items`):** Магазин внутриигровых товаров, списывающий золото с баланса персонажа при покупке.

## 📦 Как запустить проект локально

### 1. Подготовка инфраструктуры (Docker)
Для запуска базы данных PostgreSQL выполните в корне проекта команду:
```bash
docker compose up -d
```

### 2. Настройка виртуального окружения Python
Активируйте ваше окружение и установите необходимые зависимости:
```bash
# Для Windows PowerShell:
.\.venv\Scripts\Activate.ps1

# Установка пакетов:
python -m pip install fastapi uvicorn watchfiles sqlalchemy psycopg[binary]
```

### 3. Запуск веб-сервера uvicorn
Запустите бэкенд-движок прямой командой:
```bash
python -m uvicorn main:app --reload
```

После этого игровой интерфейс развернется по адресу: **http://127.0.0**

## 🛠️ Структура репозитория

* `main.py` — Сердце приложения: инициализация FastAPI, SQLAlchemy-модели таблиц, Pydantic-схемы валидации и эндпоинты игрового процесса.
* `docker-compose.yml` — Инфраструктурный файл для автоматического развертывания и настройки контейнера PostgreSQL.
* `static/index.html` — Игровой Dashboard персонажа, реализованный на чистом асинхронном JavaScript (Fetch API).
* `.gitignore` — Файл исключений, защищающий репозиторий от загрузки системного кэша и виртуального окружения.
